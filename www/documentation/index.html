Quickstart

Build and run with the default configuration.

make
./webserv
# or
./webserv config/demo.conf

The default config path is ./config/demo.conf as seen in src/main.cpp.

What this server does

  • Handles GET, POST, and DELETE.
  • Serves static files with optional autoindex.
  • Streams large files and supports range requests.
  • Parses requests incrementally and supports chunked bodies.
  • Executes CGI scripts with non-blocking pipes and timeouts.
  • Uses a single epoll loop for all sockets.

Repository layout

Path Purpose
src/ All server logic: config, HTTP, CGI, utilities, loop.
config/ Example server configuration files.
www/ Static site content and CGI scripts for testing.
rules.md Project constraints and allowed syscalls.

Guiding constraints

Webserv is constrained to C++98, uses no external libraries, and must remain fully non-blocking. All socket I/O is multiplexed through a single epoll loop.
